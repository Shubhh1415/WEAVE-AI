## 🌟 About WEAVE AI

**WEAVE AI** is an AI-powered Career Assistant designed to help students and job seekers manage multiple stages of their career journey through one intelligent platform.

Instead of switching between multiple tools for job searching, resume analysis, job matching, resume optimization, company research, and career learning, WEAVE AI brings these workflows together into a single application.

### 🚀 Core Capabilities

- 🔎 AI Job Search
- 💼 Saved Jobs
- 📄 AI Resume Analyzer
- 🎯 Resume ↔ Job Matching
- 🚀 ATS Resume Optimizer
- 🏢 AI Company Research
- 📚 AI Knowledge Base using RAG
- 📥 Downloadable AI Reports
- ☁️ Cloud Deployment

---

## 🎯 Problem Statement

Job seekers often use multiple disconnected platforms to:

- Find relevant job opportunities
- Analyze and improve their resumes
- Understand ATS compatibility
- Identify missing skills
- Compare their profile with job requirements
- Research companies
- Learn career-related topics
- Save interesting opportunities

This fragmented workflow can make the job-search process time-consuming and difficult to personalize.

### 💡 Our Solution

WEAVE AI combines these career workflows into one intelligent platform.

### 🔎 Discover → 📄 Analyze → 🎯 Match → 🚀 Optimize → 🏢 Research → 💼 Apply

## ✨ Features

### 🔎 1. AI Job Search

WEAVE AI provides a centralized interface for discovering job opportunities.

**Features**
- 🔍 Keyword-based job search
- 🏢 Company information
- 📍 Location information
- 🔗 Direct application links
- 💾 Save interesting jobs
- 🧩 Unified job-search architecture
- 🌐 External job API integrations

**Workflow**
```
User enters keyword
        ↓
Job Search Service
        ↓
External Job Sources
        ↓
Job Data Normalization
        ↓
Job Listings
        ↓
Save / Apply
```

### 💼 2. Saved Jobs

Users can save interesting opportunities and access them later.

**Features**
- 💾 Save jobs
- 👀 View saved jobs
- 🔗 Open application links
- 🗑️ Delete saved jobs
- 🗄️ SQLite persistent storage

**Workflow**
```
Job Listing
     ↓
Save Job
     ↓
SQLite Database
     ↓
Saved Jobs
     ↓
Apply / Delete
```

### 📄 3. AI Resume Analyzer

Upload your resume and receive an AI-powered evaluation.

**Supported Formats**
- PDF
- DOCX

**Analysis Includes**
- 📊 Resume score
- 💪 Strengths
- ⚠️ Weaknesses
- 📚 Missing skills
- 🚀 Improvement suggestions
- 🎯 Suitable job roles
- 💡 AI career recommendations

**Workflow**
```
Upload Resume
      ↓
PDF / DOCX Text Extraction
      ↓
Resume Text
      ↓
Gemini AI
      ↓
AI Resume Analysis
      ↓
Downloadable PDF Report
```

### 🎯 4. Resume ↔ Job Matching

Compare a candidate's resume against a specific job opportunity.

| Result | Description |
|---|---|
| 📊 Match Score | Overall resume-job compatibility |
| ✅ Matching Skills | Skills already aligned with the job |
| ❌ Missing Skills | Important skills that need improvement |
| 💡 Suggestions | AI-generated improvement recommendations |
| 🎯 Recommendation | Overall suitability assessment |

**Workflow**
```
Candidate Resume
       +
Job Details
       ↓
AI Matching Engine
       ↓
Resume / Job Comparison
       ↓
Match Score
       ↓
Skills + Recommendations
```

### 🚀 5. Resume Optimizer

The Resume Optimizer is WEAVE AI's specialized resume optimization workflow. It compares a resume against a target job description and provides ATS-focused recommendations.

**📊 ATS Analysis**
- ATS score
- ATS analysis
- Resume-job alignment

**🔑 Keyword Optimization**
- Matching keywords
- Missing keywords
- Keyword recommendations

**🧠 Skills Gap Analysis**
- Missing skills
- Skill importance
- Explanation of skill gaps

**📚 Learning Recommendations**
- Skills to learn
- Recommended learning approach
- Course / project / practice recommendations

**✍️ Resume Improvements**
- Professional summary improvements
- Key skills recommendations
- Experience bullet improvements
- ATS-friendly suggestions

**💼 LinkedIn Optimization**
- Optimized headline
- Optimized About section
- Skills to add
- Profile improvement tips

**Workflow**
```
Resume
   +
Target Job Description
        ↓
ATS Analysis
        ↓
Keyword Analysis
        ↓
Skills Gap Analysis
        ↓
Learning Recommendations
        ↓
Resume Improvements
        ↓
LinkedIn Optimization
        ↓
Final Recommendation
```

**🔐 Truthfulness Principle**

The Resume Optimizer is designed to improve the presentation and relevance of existing candidate information without fabricating:
- Work experience
- Education
- Certifications
- Employers
- Achievements
- Projects
- Unsupported skills

Research a company using AI-generated career-oriented insights.

**Information Provided**
- 🏢 Company Overview
- 🏭 Industry
- 💼 Career Opportunities
- 🧠 Relevant Skills
- 🎤 Interview Tips

**Workflow**
```

     ↓
AI Company Research
```

### 📚 7. AI Knowledge Base — RAG

WEAVE AI includes a Retrieval-Augmented Generation system for asking questions about uploaded documents.

**Supported Documents**
- PDF
- DOCX

**RAG Pipeline**
```
Document Upload
      ↓
Text Extraction
      ↓
Document Chunking
      ↓
Embeddings
      ↓
Vector Store
      ↓
Similarity Search
      ↓
Relevant Context
      ↓
Gemini LLM
      ↓
AI Answer
```

The system retrieves relevant information from uploaded documents before generating an answer.

### 📊 8. Dashboard

The dashboard provides a central interface for accessing the major WEAVE AI features. The application uses a modular Streamlit architecture with reusable UI components and independent service modules.

## ⚙️ Installation

### 1️⃣ Clone Repository
```bash
git clone https://github.com/ShubhHIT1415/WEAVE-AI.git
cd WEAVE-AI
```

### 2️⃣ Create Virtual Environment

**Windows**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

### 4️⃣ Configure Gemini API

Create a `.env` file in the project root:
```
GEMINI_API_KEY=your_gemini_api_key
```

> ⚠️ Never commit your actual API key to GitHub.

### 5️⃣ Run WEAVE AI
```bash
streamlit run app.py
```

## 🔐 Security & Privacy

WEAVE AI follows basic security practices for API credentials and user-provided documents.

**🔑 API Key Protection**

Local Development
```
GEMINI_API_KEY=your_gemini_api_key
```

Streamlit Cloud — configure the API key through Streamlit Cloud Secrets.

🚫 Never commit API keys to GitHub.

**🚫 Git Protection**

The following are excluded from version control:
```
.env
venv/
__pycache__/
*.pyc
Resume_Report.pdf
Resume_Match_Report.pdf
```

**🛡️ User Privacy**

Users should avoid uploading highly sensitive personal information unless they understand how their documents are processed. AI-generated recommendations should be treated as career assistance and not guaranteed professional advice.
